# blg-grid

BigLedger's data grid for Angular applets, published as `@bigledger/blg-grid`.

blg-grid starts as a fork of [AG Grid Community](https://github.com/ag-grid/ag-grid) 31.3.4, which is MIT licensed. The free engine becomes our code; the features AG Grid sells as Enterprise are written by us. blg-grid is not affiliated with or supported by AG Grid Ltd.

Work in progress. Plan and status: [epic #1](https://github.com/bigledger/blg-grid/issues/1).

## Rule

Never copy code from AG Grid Enterprise (`enterprise-modules`, `ag-grid-enterprise`), from any version. It is commercially licensed. Only AG Grid's MIT `community-modules` may be used.
